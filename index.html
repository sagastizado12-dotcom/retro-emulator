Notes

  • Use only games you own. No games or BIOS files are included or linked.
  • PS1: some games need a BIOS (e.g. scph5501.bin) dumped from your own console. Add it on the PlayStation tile. For multi-file games (.bin + .cue), put them in one .zip, or use .chd / .pbp.
  • Save states: use the emulator menu (Save/Load State). They're kept in this browser.
  • GameCube: no reliable in-browser emulator exists yet (Dolphin's WebAssembly port is still an early demo), so it's not supported here.
