Notes

  • Use only games you own. No games or BIOS files are included or linked.
  • BIOS: some systems need a BIOS dumped from your own hardware. Required: Sega CD, Atari Lynx, ColecoVision, 3DO. Optional: PS1, DS, Saturn, Atari 7800, PC Engine CD (syscard3.pce), Neo Geo (neogeo.zip). The file name must match exactly (tap the BIOS button to see it).
  • Multi-file disc games (.bin + .cue): put them in one .zip, or use .chd / .pbp. For ambiguous files (.zip, .bin, .iso, .chd, .cue) you'll be asked which console.
  • Arcade: the romset version must match the core (FBNeo or MAME 2003-Plus). DOS: zip the game folder.
  • Save states: use the emulator menu (Save/Load State). They're kept in this browser.
  • GameCube: no reliable in-browser emulator exists yet (Dolphin's WebAssembly port is still an early demo), so it's not supported. PSP, Saturn, 3DO and DOS are experimental.
